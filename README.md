## 应用场景
1. **煤矿安全行为监控**：实时检测矿工是否进入危险区域、是否正确佩戴头盔、是否携带自救装置，及时发现违规行为
2. **钻探作业规范监管**：识别钻杆、钻机状态及矿工操作、拆卸钻杆动作，辅助监督井下钻探作业是否规范，防范机械伤害
3. **矿工安全防护核查**：自动识别采矿头盔、压缩氧气自救装置，确保矿工下井防护装备齐全，提升应急自救能力
4. **智慧矿山智能监控**：集成到井下视频监控平台，实现人员、设备、交互行为一体化智能巡检，降低人工盯屏成本

## 数据集价值
1. **安全价值**：煤矿是高危行业，本数据集覆盖人员、装备、交互行为多维目标，可用于构建井下智能安全预警系统，减少违章作业、防范事故、保障矿工生命安全。
2. **业务价值**：适配智慧矿山/数字矿山安防AI平台，可快速训练井下目标检测模型，实现人员定位、设备状态与行为合规的自动化监控。
3. **科研价值**：数据量大（超10万帧、34GB），覆盖煤矿井下昏暗、粉尘、多设备遮挡等复杂场景，样本充足、类别丰富，适合YOLO系列等目标检测模型的训练、调优与算法对比实验。
4. **工程价值**：VOC、COCO双格式标准化标注，可直接接入主流深度学习框架，便于快速二次开发与项目落地。
